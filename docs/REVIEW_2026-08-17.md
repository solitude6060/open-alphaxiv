# Repository Review — 2026-08-17

Reviewed tree: `/home/ma/Research/side_project/open-alphaxiv` on `main`
(`git log -1` at review time: `f86240b`).

## Verdict

The tree is a working **local paper workspace with a research notebook**,
plus a real Codex CLI connector. It is not yet a daily replacement for
alphaXiv's discovery + reading loop, and it does not yet use coding-agent
subscriptions other than Codex.

The docs over-claim infrastructure (Postgres, Redis, Next.js, live
OpenAI-compatible providers, Semantic Scholar graphs). The code under-claims
nothing: the FastAPI routes in `app/main.py` mostly exist. Several of those
routes are backed by stubs (hash embeddings, synthetic literature nodes,
no-op worker).
