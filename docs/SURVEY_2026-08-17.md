alphaXiv MCP tools documented at `https://www.alphaxiv.org/docs/mcp`:
`discover_papers`, `get_paper_content`, `answer_pdf_queries`,
`read_files_from_github_repository`, plus library folder tools. Transport:
Streamable HTTP at `https://api.alphaxiv.org/mcp/v1`, OAuth 2.1 or bearer
API key. Supported clients named by alphaXiv: Claude Code, Codex CLI,
Cursor, VS Code, Zed. This is the industry pattern for "use your coding
agent on papers." This repository will implement the same **pattern**
against local data and arXiv, not against alphaXiv's endpoint.

`little-alphaxiv` is the closest **UI** analogue. `arxiv-mcp-server` is the
closest **agent subscription** analogue. `paper-qa` is the closest
**answer quality** analogue. This repository already has a reader, Codex
spawn, and a research notebook that those three do not combine.

Do not vendor alphaxiv-open's Gemini pipeline as a hard dependency. Its
MIT license would allow code reuse after review; the product contract still
requires provider-neutral adapters.

## How large projects attach coding-agent subscriptions

Pattern observed across official docs:

1. **MCP**: the app is a tool server; Cursor / Claude Code / Codex / Copilot
   are clients. Used by alphaXiv, GitHub, Playwright, Context7, arxiv-mcp-server.
2. **Official CLI non-interactive mode**: `codex exec`, `claude -p`,
   `opencode run`, Cursor `agent -p`, Gemini CLI `-p`. Documented for
   scripts and CI. The binary or `CURSOR_API_KEY` holds the login.
3. **BYOK OpenAI-compatible HTTP**: Continue.dev, Cline, little-alphaxiv,
   paper-qa via LiteLLM. Consumes API spend, not Cursor/Claude seats.
4. **Vendor SDK**: Claude Agent SDK (API keys only for third-party products),
   Copilot SDK (GitHub documents third-party OAuth Apps), OpenAI Codex SDK,
   Cursor `@cursor/sdk` (`CURSOR_API_KEY`). Not a cookie back door.

Pattern rejected by vendors:

- Third-party harnesses that reuse Claude Pro/Max OAuth
  (`https://code.claude.com/docs/en/legal-and-compliance`; OpenCode provider
  docs state Anthropic prohibits those plugins).
- Cookie replay of ChatGPT, Claude, or Cursor web sessions.

Continue.dev and Cline are the reference **provider tables** (base URL, key,
model). They do not consume a Cursor subscription. OpenCode is the
reference **multi-subscription CLI** for ChatGPT Plus and GitHub Copilot
via documented `/connect`. Claude Pro/Max through unofficial OpenCode
plugins is out of bounds.

## Implication for this repository

A defensible "complete" recreation is:

- little-alphaxiv-class reader and discovery
- paper-qa-class citations once real embeddings exist
- arxiv-mcp-server-class MCP, pointed at **this** library
- existing Codex spawn, plus Claude Code and OpenCode official binaries
- original brand and UI

It is not a scrape of alphaxiv.org and not a Cursor cookie proxy. Cursor
in-app turns, if added later, use `agent -p` or `@cursor/sdk` with the
user's key, after MCP.
